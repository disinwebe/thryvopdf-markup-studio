ThryvoPDF Server Manager

Configure a Windows background service for shared documents. It keeps running when this manager closes, while this PC is on.

This manager controls the Windows service only. The foreground server in ThryvoPDF Markup Studio is separate and stops when that app closes. Do not run both on the same port or data folder.

Configuration

Installing grants the Windows LocalService account inherited Modify access to this folder and its contents. Choose a dedicated local folder; restrict access because it contains accounts and documents. Do not share a data folder with a running server. To change settings, uninstall the service and install it again; data is not deleted.

Service actions explicitly request administrator approval. Uninstall leaves the data folder and its LocalService permissions in place. Stop and uninstall the service before uninstalling or upgrading this manager.

Connect and protect

The service uses unencrypted HTTP. Use a trusted network; the standalone server supports TLS via its documented configuration. Windows Firewall is not changed automatically.

For LAN access, an administrator can create a scoped inbound TCP rule for the selected port and trusted private network in Windows Defender Firewall. Do not expose this service publicly.

For a consistent backup, stop the service and copy the entire data folder securely, including users.json and docs. Start it again afterward. The initial admin password, if generated, is in ADMIN-INITIAL-PASSWORD.txt inside the data folder, restricted to Administrators, SYSTEM and LocalService. An administrator should read it privately, change the password at first login, and delete the file.
